Campaign and quiz files preserved separately from Centerscore’s school drama.[1][2]

The add-on

Centerscore built Surviving High School around downloadable stories. This RAR contains a Campaign folder with separate .exp files, including three quiz entries. The filenames reference various SHS production labels, including shs08.[1][2]
