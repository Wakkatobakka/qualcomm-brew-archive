Associated credits: Shiny Entertainment — original franchise; Gameloft — documented later BREW publisher

Earthworm Jim began as a Shiny Entertainment platform game in 1994. Mobile companies later adapted the franchise for very different keypad-controlled hardware.

Release databases list a Gameloft-published BREW Earthworm Jim edition in 2010; the preserved archive is evidence of a surviving package, not proof of which source assets or code were used for that edition.
