The sample

The file listing groups meshes and other assets around ruins, a crate, a coin and a bomb. Textures named for cliffs, sky, trees and transparency are listed alongside them.[1]

Development

Qualcomm’s 2009 BREW slides show how its QX Engine combined rendering and animation with an asset pipeline from desktop tools to the handset. The presentation also shows a phone connected by USB to a desktop, with the Adreno Profiler tracking what the device draws.[2]
