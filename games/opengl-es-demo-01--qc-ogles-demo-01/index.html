The sample

The archive preserves a three-file build of Qualcomm’s ogles_demo_01. Its complete archive checksum matches the copy catalogued in the Zeebo Archive. The separate OpenGL ES 1.0.3 SDK bundle there includes its source code and a sample manual.[1][2][3][4]

Development

Dave Astle’s OpenGL ES and BREW slides point developers to four demo apps on Qualcomm’s Q3Dimension site. His presentation explains how the BREW wrappers used the handset’s graphics library, with a software implementation available for testing in the BREW SDK.[5]
