OpenGL ES Demo 02

Compiled files for the OpenGL ES Demo 02 from Qualcomm’s BREW samples.[1][2][3]

The sampleDevelopmentFiles & versionsSources

The sample

Qualcomm’s SDK sample bundle included the ogles_demo_02 source project and application manual. The archive preserves a compiled build with the same project name and four Targa image filenames that correspond exactly to names in the SDK bundle.[1][2][3]

Development

Dave Astle’s OpenGL ES and BREW slides point developers to four demo apps on Qualcomm’s Q3Dimension site. His presentation explains how the BREW wrappers used the handset’s graphics library, with a software implementation available for testing in the BREW SDK.[4]
