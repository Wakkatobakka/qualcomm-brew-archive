Galaxy on Fire 3D

Fishlabs built its own 3D middleware for a space adventure that later moved from Java to BREW.[1]

In this entry

The gameDevelopmentPeople & studiosRelease & receptionFiles & versionsSources

The game

In the original Java game, a scout ship and a few paid jobs get you started as a freelance pilot. You escort freighters, join attacks and sell the cargo you pick up on sorties to afford better ships and equipment.[1]

Development

Fishlabs began the game on Sony Ericsson handsets using HI Corporation’s Mascot Capsule 3D engine. It built its own middleware to gain control over performance and how the game looked. Computer Graphics World reported in April 2006 that a BREW edition was already in development.[2]

Fishlabs CEO Michael Schade says the studio later brought the game to Zeebo using its ABYSS engine, code from the iPhone version and some of the 3D assets from the BREW phone game. The console adaptation added analogue controller support.[3]

People & studios

Fishlabs

Developer (Original Java game and BREW production)[2]

Release & reception

Pocket Gamer reviewed Galaxy on Fire on Java in September 2006. In the same year, Schade told Computer Graphics World that the game also had short action sequences for play in spare moments. His October 2009 interview confirms the BREW build supplied artwork for Zeebo.[1][2][3]
