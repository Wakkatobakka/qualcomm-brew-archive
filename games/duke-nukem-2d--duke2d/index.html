Duke Nukem 2D

Duke’s earlier MachineWorks phone game is a side-scroller from 2004.[1][2]

In this entry

The gameDevelopmentPeople & studiosRelease & receptionFiles & versionsSources

The game

MachineWorks Northwest made a side-view Duke Nukem Mobile for handsets. Its stages put Duke up against the alien occupiers familiar from the series. MachineWorks also released a first-person game called Duke Nukem Mobile on the Tapwave Zodiac the same year.[1][2]

Development

Programmer Seth Robinson’s project list gives the 2004 BREW game and the 2004 Tapwave project separate entries. He returned to BREW for MachineWorks’ first-person Duke Nukem Mobile 3D in 2005.[3]

Release & reception

SkyZone’s product description, transcribed by MobyGames, advertised 15 levels across multiple locations. The catalog lists both Java and BREW versions in 2004.[1]

Edition & research notes

The archive’s 2D label comes from the collection. The package uses duke for its module and includes separate sound, level and enemy files. Its carrier, build date and supported handsets are unresolved.[4]
