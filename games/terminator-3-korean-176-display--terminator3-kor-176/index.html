Terminator 3 (Korean, 176 display)

A 176-labelled Terminator 3 phone package with a Korean character-set resource.[1][2]

In this entry

The gameFiles & versionsSources

The game

The RAR filename includes “kor” and “176.” Inside the Terminator3 directory is a resource named ksc5601.ft. KSC 5601 is a Korean character set that includes Hangul and Hanja.[1][2]
