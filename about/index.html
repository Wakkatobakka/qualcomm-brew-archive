ABOUT THIS PROJECT

An old software archive.
A new way to find what's inside.

Somewhere in a large ZIP file, there might be a game you didn't even know existed. This independent catalog is here to make those discoveries possible.

What is BREW?

BREW stands for Binary Runtime Environment for Wireless. Qualcomm announced the platform in 2001 as a way to bring downloadable software—including games—to mobile phones. It became one of several distinct worlds of pre-smartphone games.

These releases were often tied to carriers, devices and display sizes. A surviving package doesn't automatically tell us which original handset it belonged to, or whether it works in a modern player.

Where did this collection come from?

The Internet Archive item Qualcomm BREW Games ↗ identifies a community upload from August 2021, described as a combination of two earlier collections. Its ZIP contains folders named brew2010 and brew2018.

The folder labels are kept exactly as preserved. They're not verified game release years.

Our file-level inventory found 104 individual RAR or ZIP packages and one readme. Some packages are different display editions; some are utilities, demos or additional content. That's why we talk about packages rather than claiming 104 unique retail games.

What's on each page?

Each entry records the original archive path, filename, package size, SHA-256 fingerprint, archive format, and the filenames found inside. Identifications that remain uncertain are labeled accordingly.

The goal is a search-friendly public record that people can use to rediscover, research and cross-reference these files—not to guess at missing facts.

Can I play them?

Some BREW titles can be investigated or played using community preservation work and compatible runtimes, including the separate Omni Player project. This catalog does not claim that every package is playable, and does not distribute the games themselves.

The first step is finding out what's here. When compatibility and original device information are established, those findings can become part of the historical record too.

RESEARCH & EDITORIAL METHOD

The story behind each file

The catalog now adds short game histories and source links where surviving records support them. Contemporary announcements, release databases, and period reviews are favored over unattributed summaries.

Each page labels its evidence: “Documented game history” for coverage of the named game, “Related mobile history” for a franchise or other platform edition, and “Archive evidence only” where credits or a title cannot be verified. A developer of a PC, arcade, Java, or iPhone version is not automatically credited for a BREW port.

A cataloged archive is not proof that a game has been played, preserved with legal permission from a rights holder, or matched to every handset version. Source folders named brew2010 and brew2018 are not game release dates.
